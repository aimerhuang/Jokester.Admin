# 公网 App API 安全加固 PRD

## 1. 文档信息与发布原则

| 项目 | 内容 |
| --- | --- |
| 目标产品 | Jokester App API、后台管理 API、媒体访问链路与相关基础设施 |
| 文档目标 | 建立面向公网发布的安全基线、责任边界、验收证据和发布门禁。 |
| P0 定义 | **公网发布阻断项**。任一 P0 未完成、验收失败、证据缺失或风险例外未获批准，均不得向公网开放对应能力。 |
| P1 定义 | 首发后近期完成的运营与治理加固；应有负责人、依赖和目标日期。 |
| P2 定义 | 持续验证、周期性审查与能力成熟度建设。 |
| 业务约束 | 尽量不改变现有 JWT、RBAC、积分和生图业务目标；允许为安全目的调整 Token、媒体 URL、管理端登录和 AI 任务合约。 |
| 非目标 | 本期不建设面向第三方开发者的开放平台，不重构业务领域模型。 |

### 1.1 发布原则

- 默认拒绝：未显式声明为公开的接口必须认证；未显式公开的媒体必须私有。
- 最小权限：身份、角色、资源归属和数据范围均应独立校验，不能只依赖前端隐藏或 Controller 路由。
- 纵深防御：网关负责网络、TLS、WAF 与第一层限流；应用负责认证、授权、配额和业务一致性。
- 安全失败：认证、私有媒体、成本控制和高风险限流的关键依赖异常时，不得回退为公开、无限制或跳过校验。
- 可证明：每一项 P0 都必须具备可复查的测试、配置、扫描或演练证据。

## 2. 背景、范围与风险概述

服务计划面向公网 App 使用，但当前主要按内部后台 API 形态实现。已有 JWT、权限和 Redis，仍需防范凭据泄露、资源越权、自动化滥用、媒体泄露、高成本调用和基础设施误配置。

本 PRD 覆盖以下边界：

- App 公开与登录 API、管理后台 API、运维端点；
- 反向代理、CDN/WAF、应用进程、MySQL、Redis、对象存储；
- App/管理 Web 客户端的 Token 与媒体访问；
- 邮件验证码、AI Provider、Provider 回调与服务端外部 URL 下载；
- CI/CD、发布物、日志、监控与告警。

### 2.1 威胁模型

| 攻击者/场景 | 主要攻击路径 | 需要优先保护的对象 |
| --- | --- | --- |
| 匿名互联网攻击者 | 端口扫描、撞库、账号枚举、超大请求、CORS 误配、SSRF | 公网边界、账号、可用性、基础设施 |
| 恶意登录用户 | 水平越权、批量读取、配额竞争、私有媒体猜测、积分套利 | 用户数据、积分、AI 额度、私有文件 |
| 被盗用账号/Token 持有者 | Refresh Token 重放、长效会话、改密后继续访问 | 会话、角色、个人数据、管理能力 |
| 恶意上传者 | 伪造 MIME、SVG/HTML、图片炸弹、恶意元数据 | API 进程、对象存储、浏览器用户 |
| 伪造代理或 Provider 请求者 | 伪造 `X-Forwarded-For`、Webhook 重放、伪造回调 | 限流、审计、任务状态、成本结算 |
| 管理账号失陷者 | 高权限登录、RBAC 改写、日志读取、用户接管 | 管理面、密钥、全量业务数据 |

### 2.2 数据与媒体分类

| 分类 | 示例 | 最低控制要求 |
| --- | --- | --- |
| 认证秘密 | 密码、JWT、Refresh Token、验证码、API/Provider 密钥 | 不写入业务日志；传输加密；密钥和 Refresh Token 仅保存可验证的哈希或受控 Secret 引用。 |
| 私有/敏感数据 | 邮箱、IP、设备摘要、AI 提示词、参考图、AI 生成图、用户操作关联信息 | 默认私有；最小权限访问；定义保留、删除与导出范围。 |
| 内部运营数据 | 配额、成本、风控命中、管理日志、告警 | 仅授权员工可访问；记录访问审计；保留期限可配置。 |
| 公开数据 | 已发布博客、明确标记为公开的博客图片 | 独立公开存储前缀/域名；不得与私有对象混用。 |

**媒体策略：** 用户参考图和 AI 生成图默认私有；仅资源所有者或被明确授权的主体可访问。博客公开图片使用独立的公开路径。私有对象不得经应用静态目录或可猜测的长期 URL 直接暴露。

## 3. 安全架构与接口分区

### 3.1 推荐公网拓扑

```text
App / Admin Web
  -> DNS / CDN / WAF
  -> HTTPS Load Balancer / Reverse Proxy :443
  -> Jokester API :127.0.0.1 或私网子网
  -> MySQL / Redis / Object Storage / AI Provider（私网或受控出站）
```

- 公网只开放 `80`（仅跳转至 HTTPS）和 `443`；Kestrel、MySQL、Redis、对象存储管理端不允许直接公网暴露。
- App API 使用独立 API 域名；管理后台使用独立管理域名，管理账号与普通 App 账号隔离，并强制 MFA。
- 生产环境关闭 Swagger、开发管理员引导和其他调试端点。健康检查仅供内网、负载均衡或网关白名单调用。
- `ForwardedHeaders` 仅信任已登记的负载均衡/反向代理 IP 或网段。来自其他来源的转发头必须忽略；日志和限流使用处理后的真实客户端 IP。

### 3.2 接口和媒体分区

| 分区 | 范围 | 强制访问策略 |
| --- | --- | --- |
| App 公开接口 | 注册、登录、刷新、公开博客阅读、待审核评论提交 | HTTPS、显式匿名、基础限流、验证码/反自动化、统一错误信息。 |
| App 登录接口 | 积分、个人资料、AI 生图、私有媒体 | JWT、资源归属校验、用户配额、审计脱敏。 |
| 管理后台接口 | 用户、角色、菜单、站点、日志、内容管理 | 独立域名、强制 MFA、JWT + RBAC、受控管理员账号、关键操作审计。 |
| 运维接口 | 健康检查、部署诊断、管理员初始化 | 生产关闭或限制为内网/网关白名单；一次性初始化能力执行后自动禁用。 |
| 私有媒体 | 参考图、AI 结果、用户上传附件 | 对象存储私有；经鉴权下载接口或短期签名 URL 访问。 |
| 公开媒体 | 已发布博客图片 | 独立的公开存储路径/CDN 域名；撤回后能清理或失效缓存。 |

## 4. P0：公网发布阻断项

| 编号 | 风险与目标 | 强制要求 | 验收证据 |
| --- | --- | --- | --- |
| P0-01 | 密钥与凭据泄露 | 轮换 JWT、数据库、Redis、SMTP、AI Provider、Bootstrap 密钥；生产密钥仅从 Secret Manager 或受控部署环境注入。扫描 Git 工作区/历史、镜像、发布目录、CI 输出和日志。 | 扫描报告；每类旧凭据认证失败的记录；轮换时间、责任人和应急回滚窗口。 |
| P0-02 | 安全公网边界 | 应用仅监听回环地址或私网；网关终止 TLS，HTTP 自动跳转 HTTPS；设定 TLS 最低版本、证书链、HSTS 和基础安全响应头；生产 Swagger/初始化端点不可达。 | 外部端口扫描、TLS/Headers 检查、监听配置快照和网关规则。 |
| P0-03 | 代理头伪造 | 只信任指定代理；不能由公网客户端伪造 `X-Forwarded-For` 改变审计来源、登录冻结或限流 Key。 | 伪造转发头的集成测试；代理 IP 配置与生产日志样本。 |
| P0-04 | 默认匿名暴露与越权 | 配置全局 Fallback Policy；只有显式 `[AllowAnonymous]` 且位于公开接口清单的端点可匿名访问。资源读写由服务层再次基于当前主体、角色和所有者/范围校验。为隐藏资源存在性的一类资源统一使用 `404`，其余无权限统一使用 `403`。 | 公开接口清单；新增 Controller 默认 `401` 的测试；用户 A 针对用户 B 的读取、修改、删除负向测试，无数据或副作用泄露。 |
| P0-05 | 管理面接管 | 管理后台使用独立管理域名、独立受控管理员账号和强制 MFA；普通 App 用户不得复用为管理员。高权限操作保留操作者、时间、对象和结果审计。 | MFA 强制流程测试；普通账号登录失败测试；管理员权限与审计记录样本。 |
| P0-06 | 审计和异常日志泄密 | 认证、注册、改密、刷新、登出、上传不记录请求体；令牌响应不进入审计。其余审计按字段白名单和长度限制记录。认证头、Cookie、密码、Token、验证码、密钥、文件二进制/Base64、AI 提示词及第三方原始错误不得进入审计、异常、网关或 HTTP Client 日志。 | 在 JSON、表单、multipart、异常与外部调用中注入伪造敏感值，证明日志库和日志平台均无残留。 |
| P0-07 | 认证、验证码和高成本滥用 | 网关和应用均实施共享状态的分区限流；至少覆盖登录、注册、发送/校验验证码、评论、上传和 AI 任务创建。按 IP、账号/邮箱、用户和接口分区，返回 `429` 与 `Retry-After`。登录失败信息一致，验证码有冷却期和尝试上限。 | 阈值并发测试；非攻击用户不受影响的验证；429/Retry-After 响应、指标与告警样本。 |
| P0-08 | AI 成本失控与重复提交 | 定义用户每日额度、每分钟任务数、用户并发、全局 Provider 并发及异常成本熔断阈值。AI 创建使用幂等键；积分采用预留、确认、失败退款的明确状态机。超额度、排队积压或 Provider 错误率超阈值时停止创建新任务，不扣未完成任务额度并告警。 | 重复提交、并发创建、Provider 超时/失败/回调重复的状态机测试；用户和 Provider 维度成本报表。 |
| P0-09 | Refresh Token 重放与会话失效 | Refresh Token 仅保存哈希；采用 session/token family，使用 Redis Lua 或等效原子 compare-and-consume 完成轮换。并发刷新仅一个成功；已消费 Token 再次使用时撤销会话族并记录安全事件。Access Token 有固定 `iss`、`aud`、算法白名单、短有效期（10–15 分钟）与 `jti`/会话标识。登出、禁用、改密、降权有明确的最长失效时限。 | 并发刷新与重放测试；旧 Token 存储检查；各撤销场景的 API 与日志结果。 |
| P0-10 | 浏览器会话与跨域误配 | CORS 生产缺少精确 `AllowedOrigins` 时启动失败；禁止通配 Origin、反射 Origin 以及宽泛 Origin 与凭据组合。若管理 Web 使用 Cookie，必须设 `Secure`、`HttpOnly`、合适 `SameSite`，并使用 CSRF Token 或严格 Origin 校验。认证/个人数据响应禁止缓存。 | 配置缺失/通配配置启动失败测试；非白名单 Origin、CSRF、Cookie 属性和缓存响应测试。 |
| P0-11 | 私有媒体泄露 | 私有媒体迁出静态目录并使用私有 Bucket/路径；通过资源鉴权下载或短期签名 URL 访问。签名 URL 必须绑定对象和用途、设置 TTL，并在删除/撤销后失效。公开博客图片与私有媒体的域名或存储前缀隔离。 | 未登录、非所有者、篡改路径、过期 URL 和已删除对象的访问测试；对象存储策略快照。 |
| P0-12 | 上传解析与内容攻击 | 禁止 SVG、HTML 和未明确支持的多帧/动画格式。按文件签名验证 JPEG/PNG/WebP；忽略原始扩展名，使用服务端生成对象名。服务端解码重编码并清除 EXIF/GPS；限制文件大小、像素、宽高、帧数、解码时间和内存。上传区不可执行脚本，失败时不残留对象。 | 版本化攻击样本集：伪 MIME、双扩展、HTML/SVG、polyglot、损坏图、超像素和压缩炸弹；成功与拒绝记录。 |
| P0-13 | SSRF、伪造回调与外部调用风险 | 服务端下载 Provider URL 时，仅允许 HTTPS 和受控域名/来源；解析与连接后均拒绝回环、私网、链路本地和云元数据 IP；限制重定向、大小和超时。Webhook 必须验签、校验时间窗、使用事件 ID 幂等记录，安全处理重复/乱序事件。 | 私网 URL、DNS 重绑定、重定向、超大下载与伪造/重复 Webhook 的自动化测试。 |
| P0-14 | 秘密与依赖风险进入发布 | CI 在合并和发布阶段执行秘密扫描与依赖漏洞扫描；命中未批准的高危结果阻断构建或发布。P0 所需的授权、限流、Token、媒体和上传测试纳入发布前自动化安全冒烟。 | CI 作业链接、规则/严重性阈值、例外审批及到期时间、发布前测试报告。 |

### 4.1 P0 限流初始基线

初始值应通过灰度后的指标调整，但 P1 调优不得移除 P0 的硬性防护。

| 接口类别 | 维度 | P0 初始限制 |
| --- | --- | --- |
| 登录 | IP + 用户名 | 每 10 分钟 10 次失败；连续失败触发 15 分钟冻结或递增退避。 |
| 邮件验证码 | IP + 邮箱 | 每分钟 1 次、每小时 5 次、每天 10 次；错误尝试达到上限即失效。 |
| 注册 | IP + 设备/风险标识 | 每小时 5 次。 |
| 评论提交 | IP | 每分钟 3 次、每天 20 次；限制链接数。 |
| AI 生成 | 用户 | 每分钟 2 个任务、并发 1 个；每日额度由运营配置。 |
| AI 上传 | 用户 | 单文件 10 MB、每分钟 12 次。 |
| 普通读取 | IP | 每分钟 120 次；超额返回 429。 |

### 4.2 当前未关闭的发布阻断

截至 2026-08-11，代码侧已实现默认授权、短期 JWT 与 Refresh Token family、应用层限流、
私有 AI 媒体、图片解码重编码、AI 幂等/额度/积分事务及 Provider 租约与熔断。以下事项仍需在
预发布或生产环境提供验收证据；未关闭前不得据此仓库状态宣称可公网发布：

- 轮换 Git 历史、旧发布物和日志中可能出现过的 JWT、数据库、Redis、SMTP、Bootstrap 与
  AI Provider 凭据，并使用正式秘密扫描器复核历史、镜像和 CI 输出。
- 验收网关 TLS、HSTS、80/443 暴露面、应用私网监听、可信代理、伪造转发头和生产 CORS。
- 建立独立管理域、管理员身份隔离和强制 MFA。
- 补齐验证码错误上限、登录失败冻结、WAF 第一层限流，以及认证、成本、熔断和安全事件告警。
- 执行全部数据库迁移，验证 Redis 持久化/故障转移、完整登录会话撤销链路和旧 AI 媒体迁移。
- 将私有媒体迁移到私有对象存储或完成等效风险验收，并补齐 DNS 重绑定、重定向、私网 IP、
  Webhook 验签/幂等和版本化攻击样本压力测试。
- 在 CI 中把秘密扫描、依赖漏洞扫描、授权矩阵和安全冒烟设为发布门禁。

## 7. 失败模式与安全降级

| 失效场景 | 安全行为 | 告警与责任 |
| --- | --- | --- |
| Redis/共享限流状态不可用 | 登录、验证码、上传、AI、评论采用 fail-closed 或预定义的保守本地限制；不得无限制放行。 | 告警至后端和平台负责人，记录受影响接口与降级开始时间。 |
| AI Provider 不可用、超预算或队列积压 | 停止新任务创建或返回受控重试响应；不扣未完成额度；对已预留任务按状态机确认或退款。 | 成本/错误率告警至运营与后端负责人。 |
| 对象存储或签名服务异常 | 私有媒体拒绝访问，不回退到公开静态 URL；公开博客媒体按独立 CDN 策略处理。 | 平台告警；记录对象、用户和失败原因。 |
| 代理信任配置缺失/不可信 | 生产启动失败，或忽略所有非可信转发头；不得把客户端声明当作真实 IP。 | 部署阻断，平台负责人处理。 |
| 秘密扫描命中 | 阻断发布；轮换暴露凭据，评估日志/镜像/Git 历史影响范围。 | 安全负责人负责分级、处置与复盘。 |
| Refresh Token 重放 | 撤销 Token Family，记录用户/会话/IP/设备摘要，按策略通知用户或触发账号保护。 | 后端与安全负责人接收告警。 |

1. AI Provider 是否保留、训练或跨境处理提示词、图片和账户标识；允许区域及故障回退策略。

## 9. 验收证据矩阵与发布门禁

每个 P0 项至少记录以下内容：前置环境与账号、测试步骤、负向绕过场景、预期 HTTP 状态/数据变化/日志事件/指标、证据链接、执行人、复核人和日期。

### 9.1 公网发布门禁

公网发布必须同时满足：

1. 所有 P0 项完成，且每项均有有效验收证据；未批准或已过期的风险例外为零。
2. 使用新密钥部署，旧密钥和旧 Token 的处置结果可验证；秘密扫描未命中阻断级结果。
3. 外网端口扫描只发现 `80/443`；HTTP 跳转 HTTPS；TLS、HSTS、CORS 与安全响应头符合 P0 配置。
4. 默认认证、公开接口清单、授权矩阵和管理员 MFA 已通过自动化或受控人工验证。
5. 至少通过以下安全冒烟：
   - 未授权访问返回 `401`；
   - 用户 A 对用户 B 的资源越权返回统一的 `403/404` 且无副作用；
   - 伪造 `X-Forwarded-For` 不影响真实来源、冻结或限流；
   - 非白名单 CORS、CSRF（适用时）和管理端非 MFA 登录被拒绝；
   - 登录/验证码/评论/上传/AI 触发限流后返回 `429` 和 `Retry-After`；
   - AI 重复提交不重复扣费，Provider 故障按状态机退款或保持受控状态；
   - 并发 Refresh Token 仅一个成功，重放会撤销会话族；
   - 未授权私有媒体、过期或篡改签名 URL 均被拒绝；
   - 伪造 MIME、SVG、HTML、双扩展、畸形图、超像素和压缩炸弹上传被拒绝且无对象残留；
   - SSRF、伪造/重放 Webhook 被拒绝；
   - 敏感测试值不出现在审计、异常、网关或外部调用日志中。
6. 告警链路、AI 成本熔断、私有媒体拒绝、密钥泄露和回滚方案均完成至少一次可记录的演练。
